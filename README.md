# Portfólio — Thaiene Tessaro

## Abrir localmente
Abra `index.html` no navegador. O site é uma página única (single-page): todas as seções são acessadas pelo menu ou rolando para baixo.


## Estrutura
- `index.html`: conteúdo e links de contato.
- `css/style.css`: cores, layout, responsividade e animações CSS.
- `js/main.js`: menu mobile, animações ao aparecer na tela e indicador de progresso.


## Personalizações rápidas
1. **Contatos:** no final do `index.html`, procure `SEU_EMAIL_AQUI`, `SEU_LINK_AQUI`, `SEU_USUARIO` e `tel:+5500000000000`. Substitua pelos links e telefone reais. Você pode trocar `href` sem alterar o texto exibido.
2. **Texto:** edite os textos dentro dos blocos de seção em `index.html`.
3. **Cores:** no início de `css/style.css`, edite as variáveis de `:root`.
4. **Tecnologias:** revise a lista de conhecimentos no HTML e deixe apenas as tecnologias/conceitos que você realmente estudou.
5. **Farmi:** a cena animada é ilustrativa (não representa sensores reais nem dados de hardware). Edite a descrição conforme o escopo final do TCC.


## Publicar com GitHub Pages
Crie um repositório público, envie todos os arquivos e ative Pages em Settings → Pages → Deploy from a branch → `main` → `/ (root)`.


## Tecnologias
HTML5, CSS3 e JavaScript puro. Não exige framework nem instalação.
